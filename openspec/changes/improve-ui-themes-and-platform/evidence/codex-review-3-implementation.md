What this change does: Adds themes and Settings service/SSH tabs. Updates frontend tooling and Docker publishing.

### Must fix
1. **[P1] ARM64 images contain an AMD64 executable** — `Dockerfile:13–14`. `ARG TARGETARCH=amd64` overrides BuildKit’s automatic target value, so the workflow publishes an unusable ARM64 image. **Fix:** Declare `ARG TARGETOS` and `ARG TARGETARCH` without defaults. [Docker ARG rules](https://docs.docker.com/reference/dockerfile/#automatic-platform-args-in-the-global-scope).
2. **[P1] Echo upgrade breaks per-client limits behind reverse proxies** — `go.mod:10`, `internal/server/server.go:54`. Echo 5.4.4 defaults to the socket address, unlike 5.0.4’s forwarded-header behavior. Every client behind one proxy now shares the login/API limits, and audit logs record the proxy address. **Fix:** Explicitly configure `IPExtractor` with trusted proxy addresses.
3. **[P2] Host-key race protection depends on MySQL connection flags** — `internal/handlers/terminal_handlers.go:436–450`. With `clientFoundRows=true`, a conflicting no-op insert reports one affected row. Two first connections confirming different keys can therefore bypass the stored-key comparison and authenticate against different keys. **Fix:** Always reread and compare the stored key after the insert. [MySQL affected-row semantics](https://dev.mysql.com/doc/refman/8.4/en/insert-on-duplicate.html).
4. **[P2] Mailbox users can query administrative service status** — `internal/handlers/system_handlers.go:27–28`, `internal/routes/routes.go:150–151`. With RBAC disabled—the default—mailbox JWTs pass the shared authentication middleware and the permission guard becomes a no-op. **Fix:** Require an admin token before executing `systemctl`.
5. **[P2] Reconnecting can open SSH after leaving Settings** — `frontend/src/pages/settings/TerminalTab.vue:231–242`. On a reconnect, unmounting while `load()` is pending disposes the existing terminal, but the continuation still creates a credential-bearing WebSocket. That socket misses unmount cleanup and can retain a shell until idle timeout. Reproduced in memory. **Fix:** Capture the attempt generation before awaiting and reject unmounted/superseded continuations.
6. **[P2] Terminal does not work through the development server** — `frontend/vite.config.ts:14`. The HTTP proxy shorthand does not forward WebSocket upgrades, while TerminalTab connects through the frontend’s origin. **Fix:** Use `{ target: 'http://localhost:8080', ws: true }`, preserving the incoming Host/Origin. [Vite proxy documentation](https://vite.dev/config/server-options.html#server-proxy).
### Should fix
7. **[P3] Delayed initialization can undo a theme selection** — `frontend/src/stores/theme.ts:39–41`. If storage writes fail, selecting a theme while `/version` is pending works initially, then `init()` overwrites it with the stored/server default. Reproduced in memory. **Fix:** Preserve an in-memory user selection made after initialization started.
